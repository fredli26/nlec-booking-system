# NLEC Room Booking System — Admin User Guide

---

## Getting Started

**Website:** https://booking.nlec.org.au

Open the link in any web browser on your phone or computer.

---

## Step 1 — Log In

On the login screen, select **Sign in with NLEC Email**.

Sign in using your `@nlec.org.au` Microsoft account. You will be redirected back to the booking system automatically.

> Admin access is granted via SSO only. There is no admin access code.

---

## Step 2 — View the Room Schedule

Once logged in, you will see the room schedule. As an admin, you have full access to all features.

- Use the **← →** arrows or the date picker to navigate between dates.
- Press **Today** to return to today's view.
- The left sidebar lists all rooms — click the **‹** button to collapse it and give the calendar more space.
- Pending booking requests are shown as amber ⏳ blocks on the calendar.
- The **Admin Panel** button in the top right shows a badge with the number of pending requests.

---

## Step 3 — Create a Direct Booking

As an admin, you can book a room directly without going through the approval process.

1. Click and drag on the calendar to select a time slot.
2. Enter the **Event Title** and optional description.
3. Adjust the start and end time if needed.
4. Optionally expand **Advanced** to set up a repeating event (Daily / Weekly / Monthly).
5. Press **Confirm Booking**.

> Admins can create bookings even when a room is already occupied during that time period.

---

## Step 4 — Manage Booking Requests

Press the **Admin Panel** button to open the admin panel.

### Approving a Request

1. Go to the **Bookings** tab and select **Pending**.
2. Find the request and press **Approve**.
3. Edit the title, date, or time if needed.
4. Optionally set up a repeat schedule under **Advanced**.
5. Press **Confirm Approve**.

A confirmation email will be sent to the guest, and the event will be added to the Google Calendar automatically.

### Rejecting a Request

1. Press **Reject** on the booking card.
2. Enter an optional reason.
3. Press **Confirm Reject**.

### Removing a Record

Approved or rejected records can be removed by pressing **Remove** on the booking card. This archives the record and does not affect the Google Calendar event.

---

## Step 5 — Manage Admin Accounts

Go to **Admin Panel → Accounts**.

- **Add an admin:** Enter an `@nlec.org.au` email address and press **Add**. The person will receive admin access the next time they sign in via SSO.
- **Remove an admin:** Press **Remove** next to their name.
- **Email preferences:** Each admin has two checkboxes:
  - **Request emails** — receive a BCC copy when a guest submits a booking request.
  - **Confirmation emails** — receive a BCC copy when a booking is approved.

---

## Step 6 — Manage Access Codes

Go to **Admin Panel → Access Codes**.

- **Guest Code** — the code guests use to log in and submit booking requests.
- **Viewer Code** — the code for read-only access to the schedule.

Press **Save Changes** after updating either code.
